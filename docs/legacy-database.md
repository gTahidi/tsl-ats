# Legacy Database

If you migrated historical records into the **legacy-candidates** endpoint, this module shows how to find and import them into active workflows.

## Searching Legacy Candidates
1. Go to **Legacy → Search**.
2. Enter keywords (name, email, or tags) and click **Search**.
3. Results show basic details plus a *Preview* button.

## Importing to Active Candidates
1. From search results, click **Import** on a record.
2. Choose or create a **Job Posting** to link.
3. Confirm – the system creates a new *candidate* linked to the original *persona* data. The legacy record remains unchanged for audit.

## Tips
- Use filters (date range, status) to narrow results.
- Imported candidates inherit any attachments (CVs) automatically.
